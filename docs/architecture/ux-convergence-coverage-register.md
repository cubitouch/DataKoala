The [AGG-01 manifest](../audit/391/aggregation/AGG-01.md#c-batch-evidence-manifest) accounts for **17 EMBEDDED_REGISTER + 20 STANDALONE_REPORT** sources. Each feature's linked batch records generating SHA, workflow/artifact, original/recovery PR and residual gaps.

**VV** means the source completion record reports actual relevant original-resolution screenshot inspection; **BV** means executed relevant runtime/deterministic assertion or measurement, including observed failures; **SO** means source/named-test support without that runtime observation; **UV** means unverified; **N/A** is scoped nonvisual evidence. AGG-01 checked source records and remote workflow/artifact metadata; it did not download/reopen historical PNGs. VV is therefore report-derived, with specific review-chain qualifications for CAP-06/09. No screenshot is independently reverified here.

Evidence, implementation reuse, execution and product acceptance are separate. **SCOPED** acceptance means only the explicitly described subset; the full provider/UI matrix remains UV. **FAIL** marks a confirmed failed subcontract, not an assertion every part fails. **UNRESOLVED** means the central expectation lacks adequate acceptance. Every source's untested substates remain UV even where its row has VV/BV. SO source/test evidence is detailed separately; UX ownership labels alone never prove component reuse.
