# #490 — chart copy/export feedback

Manual acceptance: **Pending** against the consolidated v0.2.1 RC.

Existing chart copy already reports one global status/error notice. Characterize
and preserve it. PNG export used separate local text (including errors announced
as status); export now uses the same NotificationArea, with status on saved PNG,
alert on failure, and no notification on native Save cancellation. Remove the
competing inline text/timer. Retain capture readiness, operation/context ownership,
revision guards, synchronous duplicate exclusion and explicit safe retry.

Ownership: useChartExport and chartCopyNotification only; #487 does not rewrite
this flow or depend on it. The native `fix-90` audit captures real rendered PNGs
with controlled Save IPC, success/failure/cancel and retry. Native dialogs and
clipboard OS behavior remain separate packaged acceptance.

## Manual steps (all Pending; reuse RC-05C/18/20/21)

1. Run a query, select a chart and filters, then Copy chart. Expect one success
   status notice and a pasteable PNG matching the displayed chart/legend.
2. Safely deny clipboard access where available. Copy chart again. Expect one
   error alert, no unhandled rejection, unchanged chart/filter/selection. Restore
   access and retry the same action without rerunning the query.
3. Export PNG to a writable path. Expect a valid PNG and one Chart exported status.
4. Cancel Save. Expect no success/error generated by cancellation. Export again
   to an unavailable path (where safely reproducible); expect one error alert.
   Retry to a writable location; expect success and retained chart configuration.
5. Start capture/export and switch tabs, result or chart revision before completion.
   Expect no late notice belonging to the obsolete chart and no stuck action.
6. At normal/narrow widths inspect notice containment, readable messages and
   screen-reader polite success/assertive failure announcements.

Local native capture is unavailable without an X display. CI supplies Xvfb; its
synthetic Save outcomes do not count as native dialog/manual RC acceptance.
