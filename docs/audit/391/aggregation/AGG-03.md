## B. Methodology and provenance

1. Re-enumerated `VC05`–`VC30` and `NON01`–`NON07` IDs in the original embedded/standalone reports, then `V-01`–`V-12` in the Phase 1B audit. CAP-07's two original declarations exist in historical revision [`9ef44d8`](https://github.com/cubitouch/DataKoala/blob/9ef44d802fca7645781e1aadbe52bf47ce064089/docs/architecture/ux-convergence-coverage-register.md#L325-L326); the later register preserves their completion context. The 135 CAP/NON identifiers exactly reconcile with AGG-01's index. Earlier `UX-*` references are lineage/context rather than new original CAP candidate IDs. CAP-01–04 have no separate `VC01`–`VC04` declarations; their findings are represented through Phase 1B V records and AGG-02 inventory links. No invented IDs fill that gap.
2. Located an immutable source line for each candidate. The JSON retains source text, batch, source commit, screenshot names where stated, supporting assertion/finding text, inventory IDs, source owner and one primary Atlas entry. The five provisional leads have separate traceability. All 175 original inventory rows appear in `inventoryMappings`; 36 have no declared Atlas candidate and remain linked to their original owner/evidence rather than receiving a fabricated issue.
3. Read AGG-01/02, the inventory, architecture audit, all 37 batch records, visual documentation and harness files. AGG-02's independent ledger determines scoped evidence and failed-acceptance accounting. Original reports determine their own claimed behavior, screenshot and severity. A source-reported screenshot is **not** an AGG-03 image inspection; a synthetic IPC acceptance is **not** a live provider, OS, packaged app or screen-reader acceptance.
4. Grouped multiple declarations only where they share a concrete user action/owner and one primary correction or deliberate contract. Similar UI vocabulary alone creates a secondary relationship, not a merged defect. Each candidate has one primary owner; `relatedEntries`/`relatedCandidates` are secondary references. A group can describe a shared presentation pattern without establishing a shared implementation root cause.
5. Ranked by correctness, potential loss/security, blocked workflows, accessibility, cross-provider reach, evidence strength, dependency and regression risk. Frequency is generally **unknown**; no priority assumes telemetry. `P1` is a high-value bounded proposal, not an authorized release gate. `BLOCKED` means define policy or produce missing evidence first.

The batch manifest in JSON includes all 37 sourceHeads/runs and original dispositions. CAP-21/#422→#427 and CAP-23/#424→#428 count **once each**. AGG-01's index is a navigation comparison, never independent behavior evidence. Every structured citation is a line in a source record; inspect the exact source scenario or artifact before implementing a disputed contract.
