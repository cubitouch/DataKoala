## E. Implementation mapping

**Shared presentation and interactions:** TextInput/FieldChrome, HighlightedText, ResizableDetailPanel and notification primitives. LogRowPresentation shares badge/chevron with patterns but not row shell. CAP-19 confirms V-01 observed 42px Loki row density, without declaring identical density appropriate for patterns (58px) or traces (68px).

**Loki source-specific ownership:** LogResultExplorer owns virtualized list, local search and selection, fields, direct copy affordances and inspector content. LokiExplorer owns newest-first result cohort, optional local result filters, explicit Builder promotion and query lifecycle. LokiBuilderPanel Level is a server-query predicate, not a client-local severity badge toggle. Loki pattern View logs candidate promotion/local fallback is a different workflow; preserve its incompatible/multiple line-filter guard.

**Clipboard comparator:** CopySqlButton and other callers catch failures through a shared text transport and notifications; direct log copy ignores the rejected promise. Sharing transport/outcome handling is a bounded potential fix. Do not generalize to a single universal result/export model.
